### Pipeline C v1.1 parity (D-09.1-12): FAILS as written

The D-09.1-12 gate required Pipeline C's 1000-epoch log-return EMD within 2% of the v1.1
baseline 0.12048789. Actual 5-seed mean is **0.01545 — 87.18% drift**, well outside the gate.

**Root cause (same as Wave 2 deviation):** the v1.1 baseline was measured against a converged
2000-epoch forward pass; a 1000-epoch fresh-init run produces under-trained log-return samples
that cluster near zero (std ≈ 0.017 vs converged 0.104 vs real 0.171) and naturally produce
a SMALLER EMD against real, not a match. This is the expected physics of an under-trained
generator and matches Wave 2's structural-pass justification. Pipeline C identity vs v1.1
remains independently verified by ABL-01 round-trip (max_abs_err 4.44e-16) — the parity
metric as written is the wrong instrument at this epoch budget.

This finding actually supports the recommendation to drop Lambert W: 1000 epochs trains
Pipeline B to publication-grade fidelity (TSTR R² 0.994) but doesn't recover Pipeline C's
2-stage Lambert W chain. Halving the epoch budget (vs v1.1's 2000) is therefore safe for B
but not for C — another reason to simplify by dropping the Lambert W layer.

### Caveats (documented in summary.md and surfaced here for the orchestrator)

1. **Epoch budget** — 1000 epochs vs v1.1's 2000. Smoke (Wave 2) verified structural parity
   at 100 epochs before launching. Adequate for B; insufficient for C's full transform chain
   parity per D-09.1-12.
2. **Pipeline anchoring asymmetry (FLAG-B)** — A is fully synthetic per-window; B/C anchor
   at sampled real OD₀. ACF is shift-invariant (unbiased). PDF/CDF/Q-Q include the real-anchor
   effect at index 0.
3. **TSTR-lite sample-budget asymmetry (FLAG-E)** — synthetic LSTMs see ~19,200 windows;
   real-only baseline trains on 65. The 60× synthetic train-set advantage means the literal
   R² gap is a *lower bound*, not a matched-budget comparison. Phase 11 (EVAL-01) reports
   the matched-budget number.
4. **TSTR-lite is sanity scaffolding, not the headline TSTR.** Phase 11 owns the full
   multi-architecture TSTR.
5. **D-09.1-19 invariant preserved** — `git diff core/` shows zero changes across
   all of Phase 09.1's plan-04 work (analysis logic stays in the notebook).

### Deviations

- **D-09.1-12 fails as written** — full rationale above. Recommend revising the gate at
  CONTEXT level (i.e., either run Pipeline C at 2000 epochs to actually converge, OR adopt
  Pipeline B and drop the parity gate). The Phase 09.1 recommendation goes with the latter.
- **DTW_N_PAIRS reduced from 200 to 100** — runtime guard. Per-pipeline DTW distributions
  are still statistically informative (5 seeds × 100 synthetic windows × 64 real windows
  = 32k DTW ops per pipeline).
- **Notebook generator (`_build_analysis_notebook.py`) added** — not in the plan's
  files_modified, but kept in tree as the deterministic source for the .ipynb. This is a
  pragmatic addition to make the notebook reproducible from a single Python file.
