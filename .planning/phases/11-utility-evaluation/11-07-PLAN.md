<objective>
Close WR-05: replace the mixed legacy-global / Generator RNG pattern in `discriminative_score` (`revision/run_timegan_scores.py`) with a single explicit `numpy.random.default_rng(seed)` used for both the two 80/20 pool splits and the minibatch index draws, and add an explicit logits-vs-labels shape assertion before the accuracy computation.

Purpose: `discriminative_score` currently calls `np.random.seed(seed)` (legacy global RNG) for the two `_split` permutations and separately constructs `np.random.default_rng(seed)` for minibatches. The two splits are correlated through global-RNG order and break silently if call order changes or upstream code touches global `np.random` — and there is no determinism test for this path (closed by 11-08). A `(B,1)` vs `(B,)` logits/labels shape mismatch would broadcast to `(B,B)` and yield a meaningless accuracy without raising.

Output: A deterministic, single-Generator `discriminative_score` with an enforced shape contract. (This plan precedes 11-08, which adds the determinism test that proves this fix.)
</objective>
